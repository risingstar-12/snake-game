# Snake Game

A fun and interactive Snake Game built using React, JavaScript, and CSS.

## Live Demo

Play the game here: https://snake-game-amber-five.vercel.app/

## Features

- Start, Pause, Resume, and Restart controls
- Score and High Score tracking
- Easy, Medium, and Hard difficulty levels
- Keyboard arrow controls
- Mobile touch controls
- Food collection and score updates
- Game Over detection
- Sound effects for eating food, game over, and button clicks
- Responsive user interface

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the dependencies:

   `npm install`

5. Start the development server:

   `npm run dev`

6. Open the local URL shown in the terminal.

## Deployment

The game is deployed on Vercel.

Live URL: https://snake-game-amber-five.vercel.app/
